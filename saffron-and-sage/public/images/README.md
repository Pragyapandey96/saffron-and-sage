# Photography

Drop JPG files into this folder using **exactly** these names. Until a file
exists, the site shows an on-brand placeholder, so nothing breaks.

| File name                   | Where it appears                    | Suggested crop        |
| --------------------------- | ----------------------------------- | --------------------- |
| `hero-table.jpg`            | Homepage hero (arched frame)        | Portrait, 4:5         |
| `saffron-risotto.jpg`       | Signature dishes                    | Portrait, 4:5         |
| `charred-cauliflower.jpg`   | Signature dishes                    | Portrait, 4:5         |
| `saffron-panna-cotta.jpg`   | Signature dishes                    | Portrait, 4:5         |
| `story-kitchen.jpg`         | Homepage "Our story" (arched frame) | Portrait, 4:5         |
| `about-room.jpg`            | About page                          | Landscape, 5:4        |

Tips

- Use photos you own or have a licence for (your own photographer, or a
  stock/free library whose licence allows commercial web use).
- Export at about 1600 px on the long edge, quality 75 to 82, to keep pages fast.
- Natural, warm-toned light suits the cream and forest-green palette.
- To add more photos or rename slots, edit `src/data/site.ts` (`photos`)
  and `src/data/menu.ts` (`image`).
